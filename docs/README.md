# Documentation

This directory contains detailed guides, hardware setup instructions, and wiring diagrams for the UCT-Micromouse project:

- [2026 Course Implementation Plan](file:///Users/nicolls/proj/eee3097s/2026/UCT-Micromouse/docs/course_plan_2026.md): Documents syllabus upgrades, uniform autograded milestones, and manual Graduate Attribute (GA) design track evaluations.
- [Kernel & API Developer Guide](file:///Users/nicolls/proj/eee3097s/2026/UCT-Micromouse/docs/kernel_api_guide.md): Details the C-Kernel telemetry structure, JSON-lite command encoding, and the high-level Python API wrapper.
- [Simulink Development & Autograding Guide](file:///Users/nicolls/proj/eee3097s/2026/UCT-Micromouse/docs/simulink_guide.md): Covers model workspace configurations, C-Caller block structures, desktop co-simulation, and Gradescope autograder integration.
- [Hardware Setup & Calibration Guide](file:///Users/nicolls/proj/eee3097s/2026/UCT-Micromouse/docs/hardware_setup.md): Guides hardware interfaces, calibration multipliers, safety watchdogs, and clock rate adjustments.
- [Student Workflow Guide](file:///Users/nicolls/proj/eee3097s/2026/UCT-Micromouse/docs/student_workflow.md): Instructions for students on how to develop algorithms, test them in simulation, and deploy firmware to the physical mouse.
